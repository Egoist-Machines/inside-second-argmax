Inside a second-argmax network

Technical note

Checkpoint

This account uses ARC’s example_2nd_argmax(), whose source file is one_layer_16_hidden_94_acc_2nd_argmax.pth. It differs from the same-architecture zoo_2nd_argmax(16,10). Its SHA-256 is:

498bd9a87c469e18e824a78e55c22843c7595776f1bfc2dfe07c36e5616218bb

model.json contains the 16 input, 256 recurrent and 160 readout weights. Rows of W are receiving neurons. Updates read one old state; prediction takes the first maximum of the ten final scores.

Sixteen stored coordinates

The pseudocode and its NumPy implementation store:

c, H, L, tau, w16, w87, a, b,
z0, z3, z10, z11, z12, z13, z14, z15

These read the same physical bank, with no additional recurrent memory. Let P=(0,3,10,11,12,13,14,15) and Q=all rows except 4,5,9. Positive scales normalize carry, record, query, candidate, relay and carrier activity:

M = -u4 / W42
G = W5 · relu(u); G9 = W9 · relu(u)
cost[k] = -G * W[k,5]                 k in P
h2=M*m; h4=u4*d; h7=abs(u7)*q
h5=G*a; h9=G9*b; h[P]=cost*z

For i=1,6,8, set g_i=q-h_i/abs(u_i). Widths are w16=g6-g1 and w87=-g8, with centre v=(g1+g6)/2. Native rows define the mixed fields:

T4 = -W4 · h / u4
R7 = W7 · h / abs(u7)
H = (T4+R7)/2; L = R7-T4
tau = W5 · h / abs(u5)
K = W[5,Q] · u[Q]
c = -(W[5,Q] @ W[Q,:]) · h / K

A four-field solve recovers m,d,q,v. Learned thresholds produce d_next=relu(x-T4) and q_next=relu(R7-x); they are not exact order statistics.

circuit.json supplies fixed derived tables, with no new learned parameters. The checker reconstructs all source coefficients and compares complete histories. Keeping three separate contrast clips retains the dispersion lost by merging them into one cap.

Supplied-write law

Compare two nonnegative old states differing only at physical neuron 5 by G*δa, with δa>0, and keep the receiving input fixed. Nonnegative larger-endpoint preactivations at rows 0, 14 and 15 keep those receivers on throughout the segment. Every other ReLU secant is in [0,1]:

v[i] = G * W[i,5]
delta_h_next[i] = secant[i] * v[i] * delta_a
secant[0] = secant[14] = secant[15] = 1

For every response row, the rational verifier sums fixed terms and the negative/positive parts of the thirteen free terms. With the pinned weights, all nine score7-score[j] lower bounds and the c lower bound are positive; the tau upper bound is negative.

This retains all sixteen receiving paths. It proves a source effect, not a valid rank admission, an absolute winner or persistence through an unchecked suffix. The demo erases a feasible internal source; its reachability from another input prefix is unproved.

False-record family

For [1,0,z,0,0,0,0,0,0,0] with z∈[511/512−1/16384,511/512+1/16384], target 2 loses to maximum 0. At zero-based input 3, split the old record source for i∈{1,6,7,8}:

common[i] = abs(u[i]) * W[7,4] / abs(u[7])
contrast[i] = W[i,4] - common[i]

Other entries are zero. Remove a component by subtracting component[i]*old_h4 from the receiving preactivation, once, then run the native suffix. Removing contrast selects 2 throughout the interval; removing common query still selects 0.

The proof propagates affine states over the entire interval, checks receiving signs at both endpoints and checks all nine rival margins. The fixed true-record control, z=513/512, recomputes its gates separately. Its correct 0-versus-2 margin decreases after the contrast cut; the winner stays 0. These are diagnostic cuts, not replacement inference rules.

Reproduction and arithmetic

Use Python 3.12 or newer. Node is needed only for the browser checks.

python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r reproduce/requirements.txt
python reproduce/check_circuit.py
python reproduce/proofs.py --check results/proofs.json
node --test reproduce/browser.spec.mjs

The two exact claims need only Python’s standard library. The circuit program needs NumPy; browser recurrence tests use Node. Records: proofs, fixed examples, circuit checks.

Exact proofs interpret stored binary weights as rationals. Floating-point reconstruction uses a declared absolute tolerance. Field recovery can leave tiny positive decoded activities at closed physical gates; generated preactivation signs define events. Numerical agreement is distinct from an exact machine-arithmetic proof.

Certificate coverage is not a percentage interpreted. Unknown bounds do not identify unknown generator operations; point agreement does not assign every error a cause.
